# 003 権限トークンの試作

## 目的
原則 1「呼び出し側を信用しない」。権限は設定で狭めるのでなく、構造で最初から狭い状態にする。
自作しない（D7）。biscuit を第一候補にする。

## 作業
- biscuit（Rust の biscuit-auth）で「どの行・どの列・いつまで・何のため」を表す
- 渡すときに狭めることはできるが、広げられないことを確かめる
- 期限切れ・範囲外の拒否が、どこで・どの理由で返るかを決める
- 致命的に足りないものが出たら、それを書いて他の方式（macaroon など）を見る

## 完了条件
- [ ] 範囲外の行・列への読み書きが失敗する試験が通る
- [ ] 狭めたトークンから広げたトークンを作ろうとすると失敗する試験が通る
- [ ] 期限切れのトークンが拒否される試験が通る
