# 004 決定的シミュレーション試験の土台

## 目的
原則 5「信用は年数でなく証拠から」。時刻・I/O・故障を差し替えられる土台の上で、同じ seed なら同じ結果になる試験を回す。
最初の対象はログ（D5）。

## 作業
- 既存の道具を先に調べる（Rust の madsim / turmoil、FoundationDB と TigerBeetle のやり方）
- 時刻・ディスク I/O を差し替えられる境界をコアに置く（後から足すと全体の作り直しになる）
- 001 のログに故障（書き込みの途中で止める・ビットを反転させる・遅らせる）を注入する

## 完了条件
- [ ] 同じ seed で 2 回回すと、出力が一致する
- [ ] 故障を注入したログの復元試験が、この土台の上で 10,000 seed 回る
- [ ] 失敗した seed を 1 行のコマンドで再現できる
