# Results of 2026-11-09 in a Linux virtual machine on a laptop

The raw output of three runs of `bench/memory.sh`, the first comparison of
memory use. They are behind the memory table in
[`docs/comparison.md`](../../../docs/comparison.md).

## Machine

- A Linux virtual machine on an Apple M4 MacBook Air (32 GB), macOS
  26.6.2: Colima with the macOS Virtualization framework, 2 virtual CPUs,
  4 GiB of memory, Linux 6.8 (aarch64). The servers ran in a Debian 12
  container inside it.
- Rust 1.98.0 (the version the repository pins), Umbrachyx built with
  `--release`.
- Valkey 9.1.3 built from its release tag, default build (jemalloc). The
  client for both servers is that release's `valkey-benchmark`.
- Synthetic data only: random keys and 32-byte values generated by
  `valkey-benchmark`.

## Files

| Folder | Script | Code |
|---|---|---|
| `run-1`, `run-2`, `run-3` | `bench/memory.sh` | the commit that adds this folder |

Each pass is 200,000 SETs, fewer than the 1,000,000 of the other
scripts. A million SETs, as `bench/umbrachyx.sh` writes them to fill its
key space, took Umbrachyx past the 4 GiB this machine has, and the kernel
stopped it.

Sizes are the resident size of the server process in KiB, as `ps`
reports it. The last column is how much the second pass of SETs, over the
same key space, added per SET, in bytes.
