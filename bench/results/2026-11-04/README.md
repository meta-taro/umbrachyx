# Results of 2026-11-04

The raw output behind the numbers in the top-level README and in
[`docs/comparison.md`](../../../docs/comparison.md), kept as it came out of
the scripts so that anyone can check the tables against it.

## Machine

- Apple M4 MacBook Air (fanless, 32 GB), macOS 26.6.2, internal SSD with
  APFS, on AC power. One machine; nothing else heavy running.
- Rust 1.98.0, Umbrachyx built with `--release`.
- Valkey 9.1.3 from Homebrew, default build. The client for both servers is
  that release's `valkey-benchmark`.
- Synthetic data only: random keys and 32-byte values generated by
  `valkey-benchmark`.

## Files

| File | Script | Code |
|---|---|---|
| `umbrachyx.csv` | `bench/umbrachyx.sh` | commit `33276bf` |
| `valkey.csv` | `bench/valkey.sh` | commit `33276bf` |
| `connections.csv`, `connections.stderr.txt` | `bench/connections.sh` | the commit that adds this folder |
| `robustness.txt` | the crash tests and the simulation, see below | the commit that adds this folder |

Latencies are in milliseconds. `valkey-benchmark` reports them in coarse
buckets, so small values are rounded.

In `connections.csv`, Umbrachyx at 10,000 clients failed: it serves each
connection on its own thread, and macOS allows a process 8,192 threads
(`kern.num_taskthreads`). `connections.stderr.txt` counts the connections
it could not start a thread for.

## Robustness

`robustness.txt` is the output of:

```sh
cargo test -p umbrachyx --release --test server_crash -- --ignored --nocapture
cargo test -p umbrachyx --test crash -- --ignored --nocapture
cargo test -p umbrachyx --lib --release ten_thousand_seeds -- --ignored --nocapture
```

CI runs the same three on Linux and Windows for every change.
